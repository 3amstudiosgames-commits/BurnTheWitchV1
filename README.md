# BurnTheWitchV1
A cooking simulations where you play as a witch and serve supernatural creatures. You can take orders, cook, and serve it to the costumers to gain money in order to buy decorations and unlock more food options/costumers. (Still in development)

## Description
In the game you can move between the front counter and the kitchen. You can serve supernatural creatures that may ask for special orders or challenge you to complete almost impossible orders. You can make food and unlock them on the recipes menu. Days and weeks can pass in the game and you can save your progress, game can become harder or you can meet new customers and find new recipes.

## Getting Started
### Dependencies
Windows 10+
### Installing/Playing
- You can download the zip file game from Itchi.IO
- You can also try the game in the Itch.IO website
## Help / Bugs
- If Playing in the Itch.IO web do not use any quit buttons.  
- Right now there is no way of saving so leaving means losing any progress.  
- You can't serve any food but you can find it in the recipe menu.
- Character in front counter disappears if you talk and go back to the kitchen.
- Images that use Godot icon have no Asset assign to them yet.
- No way of re-spawning ingredients yet
